# Kael

Um estudo de personagem em Godot para Windows x64. Explore a baseplate a pé ou aproxime a câmera para ver o rosto, os óculos, a mochila, o pingente e a lanterna.

| Controle | Ação |
| --- | --- |
| WASD ou setas | Caminhar |
| Shift + movimento | Correr |
| Espaço | Pular |
| C ou Ctrl | Agachar |
| E, parado | Acenar |
| Botão direito + arrastar | Girar a câmera |
| Roda do mouse | Zoom |
| Home | Enquadrar o personagem de frente |
| Esc | Soltar a câmera ou sair |
